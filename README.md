# Автоопределение линий реза (фикс рук и ног)

## Что было сделано
Вместо жестких констант (`arm_x`, `shoulder_y`, `hip_y`), которые ломали пропорции разных моделей (у толстяка торс шире, у женщины уже), теперь **линии реза (шея, подмышка, промежность) вычисляются автоматически** по профилю ширины меша.

1. **`RiggedModel.java`**:
   - Убрано условие, из-за которого пузо качка/толстяка попадало в руки.
   - Руки режутся строго **выше подмышки**.
   - Пивот ноги ставится **точно на линию реза**, поэтому шов на шортах больше не разъезжается при ходьбе.
   - Сохранены правильный порядок матриц (сначала опустить, потом мах) и запекание растяжения в вершины.
   
2. **`mesh/MrH/rig.txt`**:
   - Добавлен параметр `auto_rig=1`, который включает автоопределение.
   - Добавлены настройки тонкой подстройки (`arm_margin`, `arm_band_pad` и т.д.).

## Что смотреть в консоли при старте
Для каждой модели будет выведена строка:
`[RIG] auto: neck=0.86 shoulder=0.79 armpit=0.73 armCut=0.098W legCut=0.38`

Если что-то будет не идеально, теперь не нужно трогать код — достаточно подкрутить параметры в `rig.txt`:
- Если у женщины рвется майка спереди → увеличь `arm_margin` (до 1.05).
- Если у толстяка остался кусок руки горизонтально → увеличь `arm_band_pad` (до 0.04).
- Если шорты режутся слишком высоко/низко → крути `leg_gap`.

Замени `RiggedModel.java` и `rig.txt`. `Engine.java` менять не нужно, все конструкторы совместимы.
