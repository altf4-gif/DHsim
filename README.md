# Фикс сломанных рук (зигзаги и растяжение)

## Почему было "как в аду" на скриншотах
Я добавил в прошлый раз жесткое принудительное растяжение (`Math.max(1.6f, ...)`). Из-за этого код брал треугольники руки и растягивал их по оси X с силой 1.6–3.5. Когда такой растянутый кусок поворачивался на 90 градусов вниз, он превращался в острые черные шипы, а текстура ломалась.

## Что сделано сейчас
1. **Убрано принудительное растяжение.** В `RiggedModel.java` больше нет жесткого `armStretch = Math.max(...)`. Теперь по умолчанию он равен `1.0f` (не трогает размер рук). 
2. **`Engine.java` больше не перебивает конфиг.** Раньше в `Engine.java` было прописано `new RiggedModel(..., 0.08f)`, и это значение намертво перебивало любые настройки из `rig.txt`. Теперь я передаю `-1f`, и код **всегда читает настройки из `rig.txt`**.
3. **`rig.txt` теперь рулит всем.** Я выставил там `arm_x = 0.06` и `arm_stretch = 1.0`. 

## Как крутить, если руки всё ещё не идеальны (в файле rig.txt):
Тебе больше не нужно перекомпилировать код, просто меняй числа в `mesh/MrH/rig.txt` и перезапускай игру:

* **`arm_x`** — определяет, где рука отрезается от туловища.
   * Если руки **внутри тела** (туловище черное/рваное в месте крепления) — уменьшай `arm_x` (попробуй `0.04`, `0.02`).
   * Если рука **оторвана** и между ней и туловищем дырка — увеличивай `arm_x` (попробуй `0.08`, `0.10`).
* **`arm_stretch`** — длина рук.
   * `1.0` — оригинальный размер.
   * `1.1` — `1.3` — если хочешь, чтобы они были чуть длиннее (при этом зигзагов больше не будет, это плавное растяжение).

Замени файлы из архива, запусти `build.bat`. Если руки всё равно выглядят не так — просто меняй цифру `arm_x` в `rig.txt`.
