# Исправление рук (Запекание в вершины + rig.txt)

## Что было сделано
1. **`RiggedModel.java`** полностью заменен на версию с правильной логикой:
   - Растяжка рук запекается прямо в вершины при загрузке (а не в матрицу, как было в сломанной версии).
   - Плечевой колпак остается на месте, шов не рвется.
   - Длина руки рассчитывается автоматически по `fingertip_y`.
   - Правильный порядок матриц для анимации (сначала опускание, потом мах).
   - Метод `renderShadow` на месте.

2. **`Engine.java`**:
   - В вызовах создания моделей (Качок, Толстяк, MrH, Женщина) флаг `dropShelf` установлен в `false`. Плечо теперь режется у сустава, а не отрезается "полка".

3. **`mesh/MrH/rig.txt`**:
   - Обновлен конфиг с новыми параметрами.

Замени все три файла и запусти `build.bat`.
