# LWJGL 3D Engine Starter

Минимальный каркас 3D-движка на Java 21 + LWJGL 3.4.3 + JOML.
Демо: вращающийся цветной куб в окне 800x600.

## Требования
- Windows 10/11
- JDK 21 (батник `setup.bat` может установить через winget)
- Подключение к интернету для первой установки библиотек

## Быстрый старт

1. Распакуйте архив в любую папку (без пробелов в пути желательно).
2. Запустите `setup.bat` — он проверит JDK и скачает LWJGL + JOML в папку `lib/`.
3. Запустите `build.bat` — скомпилирует исходники в `out/`.
4. Запустите `run.bat` — откроется окно с вращающимся кубом.

## Структура

```

lwjgl3d-engine/
├── setup.bat      # установка JDK (winget) + скачивание библиотек
├── build.bat      # компиляция исходников
├── run.bat        # запуск демо
├── lib/           # сюда скачиваются jar-файлы (создаётся setup.bat)
├── out/           # скомпилированные классы (создаётся build.bat)
└── src/main/java/com/example/engine/
├── Main.java
├── Engine.java
├── Window.java
├── ShaderProgram.java
├── Mesh.java
├── Camera.java
└── Renderer.java

```

## Классы движка

| Класс | Назначение |
|-------|-----------|
| `Window` | Создание окна GLFW, OpenGL-контекст, события |
| `Renderer` | Очистка буферов, включение depth test |
| `ShaderProgram` | Компиляция и линковка GLSL-шейдеров, uniform-переменные |
| `Mesh` | VAO/VBO, загрузка вершин, отрисовка |
| `Camera` | Матрицы вида и проекции |
| `Engine` | Главный цикл, связывание компонентов |
| `Main` | Точка входа |
